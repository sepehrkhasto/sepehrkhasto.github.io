Aegis Planner، نسخهٔ وب · طراحی و توسعه، متن‌باز، نسخهٔ 7.1.0

۱۴۰۵

github.com/sepehrkhasto/aegis-zk-planner · Django 4.2, Web Crypto API, Argon2, django-csp, GitHub Actions

  • طراحی و پیاده‌سازی برنامه‌ریز با معماری دانش صفر؛ داده‌ها در مرورگر با AES-256-GCM رمز می‌شوند و سرور فقط دادهٔ رمزشده را نگه می‌دارد.
  • رمزگذاری کلید داده با کلید حاصل از PBKDF2-SHA256 (۶۰۰٬۰۰۰ تکرار)، به‌گونه‌ای که تغییر رمز عبور به رمزگذاری دوبارهٔ کل داده‌ها نیاز ندارد.
  • کنترل نسخه در ذخیره‌سازی و پاسخ HTTP 409 به درخواست‌های قدیمی، برای جلوگیری از بازنویسی ناخواسته میان دستگاه‌ها.
  • مقاوم‌سازی سرور با CSP سخت‌گیرانه، هش Argon2، محدودسازی نرخ درخواست و قفل حساب؛ ۱۴۶ آزمون Django و ۵۵۶ آزمون JavaScript در CI.

Aegis Planner، نسخهٔ دسکتاپ · طراحی و توسعه، متن‌باز، نسخهٔ 2.11.10

Refinery Risk Monitor · سرپرست پروژه در تیم چهارنفره

github.com/sepehrkhasto/refinery-risk-monitor · FastAPI, SQLAlchemy 2.0, Alembic, JWT, WebSocket, scikit-learn

  • سرپرستی تیم چهارنفره از تعریف محدوده و معماری تا تحویل سامانهٔ FastAPI برای امتیازدهی زنده و پیش‌بینی ریسک؛ از سه پروژهٔ برتر درس.
